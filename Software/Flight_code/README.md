# STM32F103 四旋翼飞控系统

## 项目简介

基于STM32F103C8T6的四旋翼飞行器飞控系统，采用FreeRTOS实时操作系统，支持遥控飞行、定高悬停、自动降落等功能。

### 主要特性

- 串级PID控制 (角度环 + 角速度环)
- Mahony互补滤波姿态解算
- VL53L1X激光定高
- SI24R1 2.4G无线通信
- 自动解锁/锁定保护
- 遥控器断连自动降落
- LED状态指示
- 电池电压回传

## 系统任务

### FreeRTOS任务配置

| 任务名 | 周期 | 优先级 | 栈大小 | 功能 |
|--------|------|--------|--------|------|
| flight_task | 6ms (166Hz) | 3 | 512B | 姿态解算、PID控制、电机输出 |
| com_task | 10ms (100Hz) | 4 | 512B | 遥控数据接收、状态机处理 |
| power_task | 10s | 4 | 512B | 电源管理、自动开关机 |
| led_task | 100ms (10Hz) | 1 | 512B | 状态指示灯控制 |

### 任务优先级说明

- 优先级数值越小，优先级越低
- flight_task 优先级最高 (3)，确保姿态控制实时性
- com_task 和 power_task 优先级相同 (4)
- led_task 优先级最低 (1)，不影响飞行控制

### 任务间通信

```
com_task ──(TaskNotify)──> power_task    // 关机指令
flight_task ──(TaskNotify)──> com_task   // 故障处理完成
```

## 控制算法

### 1. 姿态解算 (Mahony互补滤波)

#### 算法原理

融合陀螺仪和加速度计数据，使用四元数表示姿态：

```
陀螺仪: 短期精度高，长期有漂移
加速度计: 长期稳定，短期有噪声

融合公式:
Gyro_corrected = Gyro_raw + Kp * error + Ki * ∫error dt

其中:
error = Acc_norm × Gravity_estimated (叉积表示姿态误差)
```

#### 参数配置

| 参数 | 值 | 说明 |
|------|-----|------|
| Kp | 0.8 | 加速度计修正权重 |
| Ki | 0.0003 | 陀螺仪零偏补偿 |
| 陀螺仪量程 | ±2000°/s | MPU6050配置 |
| 加速度计量程 | ±2g | MPU6050配置 |
| 积分时间 | 6ms | 任务周期 |

#### 输出

- 俯仰角 (Pitch): 绕Y轴旋转，抬头为正，范围 [-90°, +90°]
- 横滚角 (Roll): 绕X轴旋转，右倾为正，范围 [-180°, +180°]
- 偏航角 (Yaw): 绕Z轴旋转，顺时针为正，累积值

### 2. PID控制 (串级PID)

#### 控制结构

```
                    ┌─────────────┐
目标角度 ──────────>│   外环PID   │──────> 目标角速度
                    │  (角度环)   │
                    └─────────────┘
                           │
                           ▼
                    ┌─────────────┐
当前角速度 ────────>│   内环PID   │──────> 电机控制量
                    │ (角速度环)  │
                    └─────────────┘
```

#### 优势

- 内环响应快，能快速抑制角速度扰动
- 外环负责稳态精度
- 比单级PID具有更好的抗干扰性能

#### PID公式

```
output = Kp * err + Ki * ∫err*dt + Kd * derr/dt

其中:
err = measure - desire
```

#### 参数配置

**俯仰轴 (Pitch):**
| 环路 | Kp | Ki | Kd | 说明 |
|------|-----|-----|-----|------|
| 外环 (角度) | -3.50 | 0 | 0 | 纯比例控制 |
| 内环 (角速度) | 5.50 | 0 | 0.15 | 比例+微分 |

**横滚轴 (Roll):**
| 环路 | Kp | Ki | Kd | 说明 |
|------|-----|-----|-----|------|
| 外环 (角度) | -3.50 | 0 | 0 | 纯比例控制 |
| 内环 (角速度) | 5.50 | 0 | 0.15 | 比例+微分 |

**偏航轴 (Yaw):**
| 环路 | Kp | Ki | Kd | 说明 |
|------|-----|-----|-----|------|
| 外环 (角度) | -1.50 | 0 | 0 | 纯比例控制 |
| 内环 (角速度) | -2.50 | 0 | 0 | 纯比例控制 |

**高度环 (Height):**
| 环路 | Kp | Ki | Kd | 说明 |
|------|-----|-----|-----|------|
| 高度 | -1.3 | 0 | -0.05 | 比例+微分 |

#### 调参建议

1. **先调内环**: 确保角速度能快速跟踪指令
   - 从小Kp开始，逐渐增大
   - 加入适当的Kd抑制振荡

2. **再调外环**: 确保角度能快速稳定
   - 从小Kp开始，逐渐增大
   - 外环一般不需要Kd

3. **微调**: 根据飞行效果微调参数
   - 如果振荡: 减小Kp或增大Kd
   - 如果响应慢: 增大Kp
   - 如果有静态误差: 适当增加Ki

### 3. 滤波算法

#### 低通滤波 (陀螺仪)

```
output = alpha * newValue + (1-alpha) * preFilteredValue

参数: alpha = 0.15
作用: 滤除高频噪声
特点: 响应快，适合高频数据
```

#### 卡尔曼滤波 (加速度计)

```
预测:
P(k|k-1) = P(k-1|k-1) + Q

更新:
K = P(k|k-1) / (P(k|k-1) + R)
x(k|k) = x(k|k-1) + K * (z(k) - x(k|k-1))
P(k|k) = (1-K) * P(k|k-1)

参数: Q=0.001, R=0.543
作用: 平滑数据，滤除噪声
特点: 平滑性好，适合低频数据
```

### 4. 电机混控 (X型布局)

#### 混控公式

```
左上电机 = 油门 + 俯仰 - 横滚 + 偏航
左下电机 = 油门 - 俯仰 - 横滚 - 偏航
右上电机 = 油门 + 俯仰 + 横滚 - 偏航
右下电机 = 油门 - 俯仰 + 横滚 + 偏航
```

#### 符号说明

- 俯仰+: 抬头 (左上、右上电机加速)
- 横滚+: 右倾 (右上、右下电机加速)
- 偏航+: 顺时针旋转 (左上、左下电机加速)

#### 限幅

- 电机速度范围: 0-700 (PWM比较值)
- 偏航输出限幅: ±100 (防止过度旋转)
- 油门<50时强制停止 (安全保护)

## 飞行状态机

### 状态转换图

```
                    ┌──────────────────────────────────────┐
                    │                                      │
                    ▼                                      │
                ┌───────┐    解锁成功     ┌─────────┐     │
                │ IDLE  │───────────────>│ NORMAL  │     │
                │ (空闲) │                │ (正常)  │     │
                └───────┘                └─────────┘     │
                    ▲                        │           │
                    │                        │ 定高指令   │
                    │                        ▼           │
                    │                   ┌──────────┐     │
                    │                   │FIX_HEIGHT│     │
                    │                   │ (定高)   │     │
                    │                   └──────────┘     │
                    │                        │           │
                    │                        │ 遥控断连   │
                    │                        ▼           │
                    │                   ┌──────────┐     │
                    │                   │   FAIL   │     │
                    │                   │ (故障)   │     │
                    │                   └──────────┘     │
                    │                        │           │
                    │                        │ 电机停止   │
                    └────────────────────────┘           │
                                                         │
                    ┌────────────────────────────────────┘
                    │
                    │ 取消定高
                    ▼
                ┌─────────┐
                │ NORMAL  │
                └─────────┘
```

### 状态说明

| 状态 | 说明 | LED指示 |
|------|------|---------|
| IDLE | 空闲状态，电机停止，等待解锁 | 慢闪 (500ms) |
| NORMAL | 正常飞行，三轴PID控制 | 快闪 (200ms) |
| FIX_HEIGHT | 定高飞行，三轴PID + 高度PID | 常亮 |
| FAIL | 故障状态，遥控器断连，缓慢减速降落 | 常灭 |

### 解锁流程 (安全保护)

```
Step 1: 油门推到最高 (>900)
         │
         ▼
Step 2: 保持1秒以上
         │
         ▼
Step 3: 油门拉到最低 (<100)
         │
         ▼
Step 4: 保持1秒以上
         │
         ▼
Step 5: 解锁成功，进入NORMAL状态
```

### 状态转换条件

| 转换 | 条件 | 说明 |
|------|------|------|
| IDLE → NORMAL | 解锁成功 | 油门推到最高->保持->拉到最低->保持 |
| NORMAL → FIX_HEIGHT | 定高指令 | 遥控器fix_height=1 |
| NORMAL → FAIL | 遥控断连 | 连续10次接收失败 |
| FIX_HEIGHT → NORMAL | 取消定高 | 遥控器fix_height=1 |
| FIX_HEIGHT → FAIL | 遥控断连 | 连续10次接收失败 |
| FAIL → IDLE | 电机停止 | 所有电机速度<=0 |

## 遥控数据协议

### 数据帧格式 (17字节)

| 字节索引 | 内容 | 长度 | 说明 |
|----------|------|------|------|
| 0 | 帧头1 | 1B | 固定值 'l' (0x6C) |
| 1 | 帧头2 | 1B | 固定值 'h' (0x68) |
| 2 | 帧头3 | 1B | 固定值 'z' (0x7A) |
| 3-4 | 油门 | 2B | 0-1000, 大端序, 500为中间值 |
| 5-6 | 偏航 | 2B | 0-1000, 大端序, 500为中间值 |
| 7-8 | 俯仰 | 2B | 0-1000, 大端序, 500为中间值 |
| 9-10 | 横滚 | 2B | 0-1000, 大端序, 500为中间值 |
| 11 | 关机标志 | 1B | 1:关机, 0:正常 |
| 12 | 定高标志 | 1B | 1:切换定高, 0:不切换 |
| 13-16 | 校验和 | 4B | 前13字节之和, 大端序 |

### 校验机制

1. **帧头校验**: 前3字节必须为 'l', 'h', 'z'
2. **校验和校验**: 前13字节之和等于后4字节

### 回复数据帧 (17字节)

飞控收到遥控数据后，会回复电池电压数据：

| 字节索引 | 内容 | 长度 | 说明 |
|----------|------|------|------|
| 0-4 | 电池电压 | 5B | ASCII字符串, 如 "4.20" |
| 5-16 | 填充 | 12B | 0x00 |

## 注意事项

### 初始化

1. MPU6050初始化时会自动执行偏移校准，需保持飞机水平静止约2-3秒
2. 校准完成后才能正常飞行
3. SI24R1初始化会进行硬件自检，确保SPI通信正常

### 飞行安全

1. 首次飞行前请检查电机转向是否正确
2. 确保遥控器油门在最低位置再解锁
3. 飞行时保持遥控器与飞机之间无遮挡
4. 电池电压低于3.5V时请及时充电

### 调试

1. 日志打印会占用CPU资源，飞行时建议关闭
   - 修改 `Com_debug.h` 中的 `DEBUG_LOG_ENABLE` 为 0
2. 使用串口调试时，波特率设置为115200
3. 可通过串口观察姿态数据和PID输出

### 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 电机不转 | 油门未推到最低 | 将油门拉到最低 |
| 飞机乱飞 | MPU6050校准失败 | 重新上电，保持水平静止 |
| 遥控器断连 | 信号被遮挡 | 调整天线方向，减少遮挡 |
| 定高不稳 | 激光传感器脏污 | 清洁传感器窗口 |
