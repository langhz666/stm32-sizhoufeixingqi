# P02 Remote Controller - STM32F103C8T6

四轴飞行器遥控器固件，基于 STM32F103C8T6 + FreeRTOS 实现。

## 硬件概述

| 组件 | 型号/说明 |
|------|-----------|
| MCU | STM32F103C8T6 (72MHz, 64KB Flash, 20KB SRAM) |
| 无线模块 | SI24R1 (2.4GHz, 兼容 nRF24L01+) |
| 显示屏 | 0.96寸 OLED (SPI/I2C) |
| 电源管理 | IP5305T (集成充放电管理) |
| 输入 | 双摇杆 (ADC 4通道) + 6按键 (GPIO) |
| 调试串口 | USART1 (115200 baud) |

## FreeRTOS 任务配置

| 任务 | 周期 | 优先级 | 栈大小 | 功能描述 |
|------|------|--------|--------|----------|
| power_task | 10s | 4 (最低) | 512B | 电源管理，防止自动关机 |
| com_task | 10ms | 3 | 512B | 2.4G 数据收发 |
| key_task | 20ms | 2 | 512B | 按键扫描与处理 |
| joy_task | 20ms | 2 | 512B | 摇杆 ADC 采集与处理 |
| oled_task | 100ms | 1 (最高) | 512B | OLED 显示刷新 |

## 通信协议

### 发送帧格式 (17字节)

```
┌──────┬──────┬──────┬─────┬─────┬─────┬─────┬────┬─────┬───────┐
│ HEAD │ HEAD │ HEAD │ THR │ YAW │ PIT │ ROL │ SD │ FIX │  SUM  │
│  1B  │  1B  │  1B  │ 2B  │ 2B  │ 2B  │ 2B  │ 1B │ 1B  │  4B   │
└──────┴──────┴──────┴─────┴─────┴─────┴─────┴────┴─────┴───────┘
  'l'    'h'    'z'                                  校验和
```

- **帧头**: `0x6C 0x68 0x7A` ("lhz")
- **THR/YAW/PIT/ROL**: 摇杆数据，范围 0-1000，高8位在前
- **SD**: 关机标志 (1=关机)
- **FIX**: 定高标志 (1=切换定高)
- **SUM**: 前13字节累加和，32位大端序

### 接收帧

飞机回传数据存入 `post_buff`，包含电压等信息。

## 命名规范

### 文件命名
- `App_*` - 应用层模块
- `Int_*` - 接口层驱动
- `Com_*` - 通用工具模块
- `Inf_*` - 底层基础设施 (OLED, 字体)

### 函数命名
- `App_*()` - 应用层函数
- `Int_*()` - 接口层函数
- `Com_*()` - 通用工具函数

### 宏定义
- 全大写 + 下划线分隔
- 例: `TX_PLOAD_WIDTH`, `POWER_TASK_PRIORITY`

## 使用说明

### 首次使用
1. 上电后系统自动初始化 SI24R1 无线模块
2. OLED 显示遥控器状态信息
3. 摇杆数据实时采集并发送至飞机

### 摇杆校准
1. 将摇杆保持在中立位置
2. 长按 RIGHT_X 按键 (>1秒)
3. 系统自动采集10次取平均值作为零偏

### 微调控制
- **UP/DOWN**: Pitch 微调 (+/-10)
- **LEFT/RIGHT**: Roll 微调 (+/-10)
- **LEFT_X**: 发送关机指令
- **RIGHT_X**: 切换定高模式
